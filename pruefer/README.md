# Prüfprogramme

Noch leer. Hier entstehen zwei Programme, die ein Verfahren aus `verfahren/` nachrechnen (Aufträge A-08 und A-09).

Regeln:

- zwei verschiedene Programmiersprachen
- exakte Arithmetik, keine Gleitkommazahlen
- geschrieben von verschiedenen Subagenten, die den Code des anderen nicht sehen
- ein Verfahren gilt nur als geprüft, wenn beide Programme es annehmen
