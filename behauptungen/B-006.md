### Was das Paper sagt (arXiv:2609.14393v3, Abschnitt 1, wörtlich)

- Definition: „An R-rank decomposition of the ⟨k, l, m⟩ matrix multiplication tensor is a list of linear maps α_r : F^{k×l} → F, β : F^{l×m} → F and matrices C_r ∈ F^{k×m} for 0 ≤ r < R such that for all A ∈ F^{k×l} and B ∈ F^{l×m}, AB = Σ_r α_r(A) β_r(B) C_r. The rank of ⟨k, l, m⟩, denoted as R(⟨k, l, m⟩), is the smallest possible R such that a decomposition exists for ⟨k, l, m⟩.“
- „Theorem 1. For m ≥ 3, R(⟨3, 2, m⟩) ≥ ⌈(24m+2)/5⌉.“
- Abstract: „… at least ⌈(24m+2)/5⌉ if m ≥ n = 3 … over arbitrary fields.“
- „Theorem 1 matches Hopcroft-Kerr for m ≤ 6, proving … R(⟨3, 2, 6⟩) = 30.“ Die obere Schranke ⌈(3nm+max(n,m))/2⌉ = 30 wird nur zitiert.

### Entfaltung der Definitionen bis mathlib

- `BilinearAlgorithm K n l m r` ist eine Struktur mit vier Feldern: `alpha : Fin r → (Matrix (Fin n) (Fin l) K →ₗ[K] K)`, `beta : Fin r → (Matrix (Fin l) (Fin m) K →ₗ[K] K)`, `coeff : Fin r → Matrix (Fin n) (Fin m) K` und `correct : ∀ A B, A * B = ∑ k : Fin r, (alpha k A * beta k B) • coeff k`.
  - `Matrix (Fin a) (Fin b) K` ist `Fin a → Fin b → K`. `→ₗ[K]` ist `LinearMap (RingHom.id K)`, also K-lineare Formen.
  - `A * B` elaboriert (mit `pp.explicit`) zu `Matrix.instHMulOfFintypeOfMulOfAddCommMonoid`, dem gewöhnlichen mathlib-Matrixprodukt (AB)_ij = Σ_t A_it B_tj. Lokal zusätzlich geprüft: `(A * B) i j = A i 0 * B 0 j + A i 1 * B 1 j` für 3×2 mal 2×6.
  - `•` ist `Matrix.smul`, eintragsweise Skalarmultiplikation; `∑ k : Fin r` ist `Finset.sum` über ganz `Fin r`.
  - Das ist wörtlich Yangs R-rank decomposition mit k = n, R = r, α_r = `alpha`, β_r = `beta`, C_r = `coeff`, quantifiziert über **alle** A und B.
- `tensorRank K n l m` ist `Nat.find (exists_bilinearAlgorithm K n l m)` für das Prädikat `fun r => Nonempty (BilinearAlgorithm K n l m r)` mit der Entscheidbarkeitsinstanz `Classical.propDecidable`. `Nat.find` liefert die kleinste Zahl mit dem Prädikat; die Instanz ändert den Wert nicht (Decidable ist subsingulär). Die Existenz kommt aus dem Schulbuchverfahren `standardAlgorithm` mit n·l·m Produkten. Kein Ersatzwert, kein leerer Typ, kein Trivialfall: r = 0 und Nullsummanden sind zugelassen, verfälschen das Minimum aber nicht.
- `⌈((24 * m + 2 : ℚ) / 5)⌉₊` elaboriert zu `Nat.ceil` in ℚ mit `Nat.cast m`, Division `Rat.instDiv`. Für nichtnegative Werte ist das die gewöhnliche Aufrundung. Lokal geprüft: der Wert ist 30 für m = 6, und er ist gleich (24m+6) div 5 für 3 ≤ m ≤ 40.
- Universen: alle drei Sätze sind universenpolymorph in `K : Type u_1`. Lokal geprüft: Anwendung für `K : Type v` mit freiem Universum `v` und für `ℚ` typisiert.

### Abgleich Punkt für Punkt

Die Annahme `[Infinite L]` steht nur an Hilfssätzen in `YangN3.lean`, nicht an den geprüften Sätzen. **Stimmt.**
3. **Rangbegriff.** `BilinearAlgorithm` ist genau Yangs Zerlegung, `tensorRank` genau ihr Minimum (siehe Entfaltung). **Stimmt.**
