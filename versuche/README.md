# Gescheiterte Ansätze

Hier bleibt alles, was nicht funktioniert hat. Wer einen Ansatz beginnt, liest zuerst diesen Ordner.

Eine Datei pro Ansatz, benannt `V-xxx-kurztitel.md`:

```
# V-xxx: Kurztitel

- Ziel: (welche Behauptung, welche Stufe)
- Idee:
- Woran es scheiterte: (konkret, mit Stelle im Beweis oder Ausgabe des Programms)
- Was man daraus lernt:
- Runde und Datum:
```
